# Attribution

Provenance and attribution for borrowed structure in this plugin's skills. Nothing here is an
instruction to an agent — the skill bodies are self-sufficient, and this file exists so the
borrowing is recorded and checkable.

**Delete this file if nothing was borrowed.** An empty attribution file is worse than none: it
reads as a completed check when no check happened. Keep it only while it describes a real
baseline, and give every baseline its own section.

{{UPSTREAM_LICENCE}}, © {{UPSTREAM_HOLDER}}.

Pinned at commit **`{{UPSTREAM_SHA}}`** — the commit that was actually read, confirmed to
resolve in that repository. A later upstream revision may differ; re-read before claiming this
skill tracks it.

The pinned SHA is the point of this file. A named repository without one records that
something was borrowed but not what, which is the state the licence question cannot be
answered from later.

This repository's own licence is the one its manifest declares. This file makes no claim about
what the upstream licence does or does not require — that is not ours to assert — so the
operating rule is the conservative one: **if you copy substantial wording from the upstream
plugin into this repo, carry the upstream licence and notice with it, and state that the file
was changed.**

Name the upstream's licence in the paragraph above that names the upstream, and nowhere else.
The review step reads that paragraph for it, and only that paragraph — a licence token
floating elsewhere in this file used to satisfy the check on behalf of an upstream it had
nothing to do with.
