# gutt Quick Start

This is an alias for `/gutt-pro:setup`.

Run the full setup wizard to configure your gutt MCP server connection.

**What it does:**

1. Shows the MCP endpoint in use (Claude Code default: the gutt shared stage server)
2. Points it at your organization's endpoint if you give one (plugin option `mcp_url` in
   Claude Code, `~/.cursor/mcp.json` in Cursor)
3. Tells you to restart and authenticate

**Usage:**

```
/gutt-pro:start
```

Or use the full command:

```
/gutt-pro:setup
```
