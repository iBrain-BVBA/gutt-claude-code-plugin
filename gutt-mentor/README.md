# gutt-mentor

Onboarding and growth programs, grounded in what your organization has recorded and tracked in
your own personal memory. A fresh session picks up where you stand without you explaining it
again.

```
claude plugin install gutt-mentor@gutt-plugins
```

It depends on `gutt-pro`, which installs and enables with it.

## Try it

- "I'm joining the payments team next week. Help me get up to speed."
- "I want to get better at code reviews."
- "Check in on my onboarding plan."

## Skills

| Skill                       | What it does                                                                                                     |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `onboarding-guide`          | For a new team, engagement or system: reads the team, architecture, decisions and experts, then builds your plan |
| `mentor`                    | For growing a practice or toward a role: grounds the goal in what the org expects, then builds a program         |
| `individual-program-design` | Writes the program (goals, milestones, check-in cadence) to your personal memory                                 |
| `progress-tracking`         | Reads your program back, reports where you stand, and records the next check-in                                  |

## Where it writes

Programs, progress, blockers and open questions go to your **personal** scope, which follows
your login, so you run these yourself. `onboarding-guide` can also publish your plan to the
organization's graph, after you confirm, so the next person joining that role can learn from
it. `mentor` writes only to personal memory.

No hooks and no agents.
